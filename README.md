# Blurt!

A free, offline, pass-the-phone party word game. Describe the phrase, get your team to shout it,
pass the phone before the hidden fuse blows. Every pack free, no ads, no accounts.

```bash
npm ci
npm start            # Expo dev server (use a development build for audio/haptics)
npm test
```

See `docs/PRD.md` for the spec and `AGENTS.md` for the codebase map.
